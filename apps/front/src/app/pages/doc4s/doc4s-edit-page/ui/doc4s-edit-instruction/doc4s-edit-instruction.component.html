1. Чтобы добавить документ нажмите кнопку "Загрузить" в секции "Запрос"
Можно загрузить файлы JPG постранично.

Файлы PDF, DOC, DOCX, XLS, XLSX будут разбиты на страницы.

2. При необходимости отредактируйте свойства запроса - клик по надписи с номером

3. Нажмите кнопку "В работе" для запуска на согласование или подпись. После перевода в этот статус запрос не редактируется.

4. На электронную почту придёт сообщение о результатах согласования.

Документ будет переведен в статус "Утвеждён" или "Отказ"

5. Файлы с подписями и печатями можно скачать в секции "Ответ"
